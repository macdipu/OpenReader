# CR-READER-SELECT-OCR: select, copy, highlight, bookmark and OCR in every reader

## Request (user, 2026-11-22)
"For document if want to copy anything, then how? it has no way to copy from any document like pdf?" Then: "add copy feature also add ocr feature if it is image, before starting check all document type, what is standard in reader, how it should act in desktop and mobile, do full planning, use planning mode". Clarified: not every PDF is an image (a doc converted to PDF) so PDFs must support copy, select, highlight, bookmarks by default; image parts of a PDF get OCR; check whether other types support these. - Image viewer not needed.
- Q1 yes (app database for bookmarks/highlights); Q2 yes (Linux Tesseract in first OCR release); Q3 only model-supported languages, no language-specific work; Q4 no image viewer (user, 2026-11-22).
