Features

Everything a reader needs. Nothing it doesn't.

Built with Flutter, with its own document engines, so every platform reads files the same way.

Seven formats, one app

Page-based PDF, paginated Word, spreadsheet grid for Excel and CSV, PowerPoint slides, Markdown and plain text.

Night mode everywhere

Switch any reader to a dark theme with one tap, so late-night reading is easy on the eyes.

Private by design

Zero network calls. Your documents are read on-device and never leave it. No accounts, no analytics.

Find anything fast

Browse folders, jump to Recents and Favorites, filter by type, and search inside documents.

Open from anywhere

Open With from your file manager, drag and drop, the command line, or files shared from other apps.

Made for every screen

A bottom bar on phones, a side rail and "Open file" button on desktop, with content width that suits large windows.

Desktop integration

Right-click, Open with OpenReader.

OpenReader registers itself with your file manager, so any supported document opens in one click — and each type keeps its own recognisable icon.

  • Windows — per-user registration script, no admin rights needed.
  • macOS — appears in Finder's Open With and the Dock drop target.
  • Linux — a desktop entry adds it to your launcher and Open With menu.
  • Make it your default — one prompt in the app, for every type or just the ones you pick, like PDFs.
  • Never takes over — nothing changes unless you say so.
