One app for all your documents.

OpenReader is an all-in-one Android document reader built with Flutter. Discover, open, read, search, and navigate your PDF, Word, Excel, CSV, and text files — no accounts, no cloud upload, no server dependency.

Supported formats

PDF DOC / DOCX XLS / XLSX CSV TXT

Features

Everything a document reader needs, nothing it doesn't.

📖

Multi-format readers

Page-based PDF viewing, paginated Word documents, spreadsheet grid for Excel/CSV, and plain text reading.

🔍

File discovery

On-device document scanner, Recents, Favorites, and Search — all indexed locally.

📤

Sharing & integration

Share, File Info, Open With, and receive shared/opened files from other apps.

🔒

Works offline

All reading happens on-device with a local SQLite index for recents and favorites. No network calls.

Your documents never leave your device

OpenReader has no servers, no accounts, and no analytics. Read the full details in our Privacy Policy.
