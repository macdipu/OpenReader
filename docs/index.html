Right-click, Open with OpenReader.

OpenReader registers itself with your file manager, so any supported document opens in one click — and each type keeps its own recognisable icon.

  • Windows — per-user registration script, no admin rights needed.
  • macOS — appears in Finder's Open With and the Dock drop target.
  • Linux — a desktop entry adds it to your launcher and Open With menu.
  • Never takes over — nothing changes unless you say so.

Privacy policy

Questions

Is OpenReader really free?

Yes. There are no ads, subscriptions or in-app purchases, and you never need to register.

Does it work offline?

Always. OpenReader makes no network calls, so everything works without a connection.

Which formats can it open?

PDF, Word (.docx), Excel (.xlsx), PowerPoint (.pptx), CSV, Markdown and plain text. Legacy binary .doc, .xls and .ppt files are not supported.

Which devices are supported?

Android phones, tablets and foldables, plus Windows, macOS and Linux computers. iOS is coming soon.

Are my documents uploaded anywhere?

No. Files are read and indexed on your device and never leave it.

Why does Windows or macOS warn me?

Desktop builds are not code-signed yet. On Windows choose “More info”, then “Run anyway”. On macOS right-click the app and choose Open the first time.

Where can I report a bug or help?

On GitHub. Issues and pull requests are welcome.
